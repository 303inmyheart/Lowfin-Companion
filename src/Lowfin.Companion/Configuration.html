Lowfin Companion

Playback rules, library updates, provider access and Discord Rich Presence.

Overview & dashboard

Jellyfin 12.2 or later. Newer versions are no longer disabled solely by their version number. Actual API compatibility is still required.

This registers one icon glyph using a marked block in Jellyfin Custom CSS. Your existing CSS is retained. Disable this option to remove the block and use Jellyfin's standard plugin icon. Reload the dashboard after saving.

Playback rules & persistent resume

Configure individual movies and episodes from their Lowfin detail page. Rules are stored per Jellyfin user and apply across that user's Lowfin devices. Processing is active only when a rule is selected. Jellyfin's global completion thresholds remain unchanged.

Cover tags & media index

Lowfin draws labels inside each visible artwork frame. Original images remain unchanged. Each client can hide tags; HDR labels also require HDR playback enabled on that TV.

DVD covers SD video up to 1024 × 576. Series and seasons receive the DVD tag when more than half their available episodes are SD/DVD. Stereo stays off unless selected below.

Persistent media index

Updated from Jellyfin events, with a reconciliation every 24 hours. Run a manual check under Dashboard → Scheduled Tasks → Lowfin Companion. This does not rebuild the client's completed image cache.

Ratings providers

Credentials stay on this server. Lowfin chooses which providers and individual ratings to display, and retains its optional local ratings cache. Empty fields disable the corresponding provider.

Provider access

Otherwise only the selected users can use server credentials, including Tracearr. Other users retain their device-local configuration.

Tracearr playback statistics

Use a Tracearr Public API v2 token. Mapping uses Jellyfin user IDs, not names. The provider access selection above also applies here.

Save the URL and token before loading the server list.

Discord Rich Presence

Optional server-hosted presence, as in the supplied standalone plugin: no desktop Discord client is required. This gateway mode uses Discord user tokens and is not Discord's supported desktop RPC flow. Discord disallows automated user accounts. Tokens are encrypted in the plugin configuration. Back up and protect the separate lowfin-companion/secret-keys directory as well. Full server or key-ring access still permits decryption.

Jellyfin → Discord users

Each mapping has its own Discord gateway session. Leave the token field empty to keep its stored value. Remove the mapping to delete its token. Disable the standalone Discord plugin before enabling Companion RPC to avoid competing sessions.

Media types

Live TV shows the channel on the first line and its current EPG programme underneath. Without guide data it repeats the channel name. Valid guide start/end times provide programme progress; pauses hide timestamps.

Activity appearance & updates

Templates: {title}, {series}, {season}, {episode}, {artist}, {album}, {year}, {genres}, {type}. Playback events are coalesced per user; guide lookups are bounded to the current channel.

Artwork

Public HTTPS image URLs are resolved through Discord. Uploading local artwork is separate opt-in: it sends the selected media cover to the configured public host. No Jellyfin server token or private server URL is sent with the image.
