# Publication privacy

Run tools/check_privacy.py before every commit, push, package upload or release. Private-term checks receive their values only from a local environment file or GitHub secret; never commit the private terms themselves. Do not publish personal account/device names, private network addresses, home paths, credentials, conversation excerpts or internal usage logs. Existing images are owner-approved except the retired drawer screenshot. Preserve third-party licenses and required provenance. Compile with the neutral PathMap in the project file; inspect all DLLs and packages. Keep private audit/recovery data outside tracked paths. Companion remains version 0.7.1 until an explicit version change is requested.

# Release policy

Publish official releases only after the project owner has personally tested and approved the changes.
